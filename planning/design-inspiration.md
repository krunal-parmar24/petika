# Design Inspiration & Aesthetic Benchmarks: Petika

> **Template Name**: Petika  
> **Date**: 2026-11-23  

---

## 1. Aesthetic Direction: Neo-Editorial Bento Elegance

Petika draws inspiration from the highest echelons of contemporary digital design:
1. **Apple & Linear Bento Aesthetics**: Compact, rounded, modular content cards that present diverse data types with clear optical weights and elegant borders.
2. **Editorial Swiss Typography**: High typographic personality in display titles (Syne / Plus Jakarta Sans) contrasted with Swiss modernist clarity in body copy (Inter).
3. **Gallery-Grade Light & Obsidian Night**:
   - Dark mode is not muddy dark gray—it is deep obsidian (`#0A0D14`) accented with radiant amber gold (`#F59E0B`) that feels warm, premium, and sophisticated.
   - Light mode is not blinding stark white—it is soft alabaster (`#F8FAFC`) with crisp pure white card surfaces (`#FFFFFF`) and whisper-soft borders (`#E2E8F0`).
4. **Tactile Micro-Interactions**: Subtle border glow on card hover, fluid modal transitions, smooth category filter reflow, and instant clipboard copy feedback.

## 2. Competitive Differentiation Strategy

| Common Portfolio Weakness | Petika Commercial Countermeasure |
|---|---|
| Clunky multi-page navigation | Single-page fluid smooth-scroll with active scroll-spy |
| Dark mode only or broken light mode | Handcrafted dual-theme system with zero FOUT on reload |
| Superficial project cards with no depth | In-page interactive case study modal with full brief & metrics |
| Heavy jQuery plugins (Isotope, Slick) | 100% native Vanilla ES6+ and Bootstrap 5.3.x |
| Hardcoded colors that take hours to change | 3-tier CSS custom property token system editable in 60s |
| Non-validated, dead contact forms | Working client-side validated form with feedback banners and copy pills |
